# 학교생활 도우미

서일여자고등학교 학생과 선생님을 위한 학교 앱이에요.
급식·시간표·달력·쪽지를 한 곳에서 봐요.

```
https://eoris1225.github.io/school-app/
```

깔지 않아도 돼요. 위 주소를 열면 바로 쓸 수 있고, "홈 화면에 추가"를 하면
아이콘이 생겨서 앱처럼 열려요. 아이폰도 돼요.

| | 학생 | 선생님 |
|---|---|---|
| 급식·시간표·달력 | 봐요 | 봐요 |
| 쪽지 | 질문을 보내요 | 답하고 완료 처리해요 |
| 수행평가 일정 | 봐요 | 올리고 고쳐요 |
| 교시 시각 | 봐요 | 학교에 한 번 넣어요 |

급식·시간표·학사일정은 NEIS 열린 API에서 받아오고, 계정·쪽지·수행평가·교시
시각은 Supabase에 담아요. NEIS 인증키는 앱에 없어요. Edge Function 안에만
있고 앱은 그 함수를 불러요.

# 담긴 기능

## 홈

지금 뭘 하면 되는지 한 화면에 담아요.

- **지금 몇 교시인지** — 등교 전 / 수업 중 / 쉬는 시간 / 점심 / 하교 후.
  언제 끝나는지와 다음 교시 과목까지 같이 적어요
- 오늘 급식 한 줄. **내가 못 먹는 재료가 들어 있으면 거기부터** 알려줘요
- 다가오는 일정. 수행평가가 일주일 안이면 달력 아이콘에 `D-3` 딱지가 붙어요
- 선생님 화면은 달라요 — 답변 기다리는 쪽지 개수, 오늘 들어가는 수업이 교시별로

교시 시각을 안 넣은 학교에서는 "지금 몇 교시"가 안 떠요. 대신 오늘 수업을
알려줘요. 모르는 걸 지어내지 않아요.

## 급식

- 중식·석식, 한 주치를 한 번에
- **알레르기 경고** — 내 정보에 못 먹는 재료를 골라두면 그 메뉴에 표가 붙고
  맨 위에 "조심 3개"가 떠요. 색만으로 알리지 않아요
- 열량, 급식 인원, 원산지, 영양 정보

## 시간표

- **하루 / 한 주 / 내 수업** 세 가지로 봐요 (내 수업은 선생님만)
- 교시마다 과목 색이 달라서 훑기만 해도 무슨 날인지 보여요
- 비어 있는 교시도 자리를 남겨요. 4교시 다음에 6교시가 나오면 고장 난 줄 알아요
- **내가 듣는 과목으로 바꾸기** — 선택과목은 반마다 대표 과목 하나만 올라와요.
  줄을 눌러서 실제로 듣는 과목으로 바꿔요. 같은 이름이 나오는 다른 교시도
  한 번에 바꿀 수 있어요
- **선생님 시간표** — NEIS에 담당 교사 칸이 없어서, 학교 전체 시간표에서
  내 과목만 뽑아요. 같은 과목 선생님이 여럿이면 겹치는데 그걸 감추지 않고
  보여줘요. 들어가는 반을 좁히거나 칸을 직접 고칠 수 있어요

## 달력

- 학사일정(NEIS) · 수행평가(선생님이 올림) · 내 일정(나만 보는 메모)
- 날짜 네모를 종류별 색으로 칠해요. 여럿이면 대각선 줄무늬로 나눠요
- 종류로 걸러 보기. 선생님은 "내가 올림"도 있어요
- **수행평가 등록** — 날짜, 과목, 준비물·범위, 학년·반을 골라서. 올린 사람만
  고치고 지울 수 있어요

## 쪽지

- 학생이 과목을 골라 질문을 보내요. 그 과목 선생님 **모두**에게 가거나,
  **한 분을 콕 집어** 보낼 수 있어요
- 사진을 붙일 수 있어요. 문제집 한 쪽을 찍어 보내는 용도예요.
  긴 변 1600까지 줄이고 JPG로 다시 담아서 보통 300KB 안쪽이 돼요
- **답변완료는 선생님이 직접 눌러요.** "잠깐만요, 찾아볼게요"도 답이라
  답이 달렸는지로 셀 수가 없어요. 학생이 한 줄 더 보내면 다시 답변대기로
  돌아와요
- 선생님 쪽지함에는 찾기가 있어요. 이름·반·내용으로 찾아져요
- **새로고침이 필요 없어요** — 쪽지 안에서는 5초, 목록은 20초, 탭 배지는
  1분마다 알아서 갱신돼요. 화면을 떠나거나 앱을 내려놓으면 멈춰요

## 알림

쪽지에 답이 오면 폰에 알림이 떠요. 웹 푸시라 앱을 안 깔아도 돼요.
아이폰은 "홈 화면에 추가"를 한 뒤에 켤 수 있어요 (iOS 16.4 이상).

## 교시 시각

NEIS에 없는 정보예요. 학교마다 다르고 어디에도 공개돼 있지 않아요.
그래서 **그 학교 선생님이 한 번 넣으면 그 학교 학생 전부가 써요.**

1교시 시작만 치면 나머지가 50분 수업 · 10분 쉬는 시간으로 쭉 깔려요.
다른 데만 고치면 되고, 고친 칸은 다시 안 건드려요.

아무도 안 넣은 학교는 시각을 아예 안 보여줘요. 시간표는 그대로 나오고
"지금 몇 교시"만 안 떠요.

## 계정

- 이메일·비밀번호로 가입해요. 학교와 학년·반·번호를 고르고 시작해요
- **선생님 코드**를 넣으면 선생님으로 바뀌어요. 담당 과목을 고르면 그
  과목으로 온 쪽지를 받아요. 다시 학생으로 돌아갈 수도 있어요
- 가입하고 나면 번호·알레르기·시간표를 하나씩 물어봐요. **전부 건너뛸 수
  있어요.** 건너뛴 건 내 정보에서 언제든 할 수 있어요

### 폰을 바꿔도 따라오는 것

계정에 담겨요.

```
학교 · 학년 · 반 · 번호      담당 과목(선생님)
내가 듣는 과목으로 바꾼 칸    선생님 시간표 설정
못 먹는 재료                 내 일정
테마 색 · 화면 밝기          가입 안내 봤는지
```

기기에도 같이 담아요. 로그인을 안 해도 쓸 수 있어야 하고, 인터넷이 끊겨도
급식 알레르기와 달력은 보여야 하니까요. 둘이 다를 때 누가 이기는지는
`app-state.tsx`의 `pull`이 한 곳에서 정해요.

## 꾸미기

- 테마 색을 고르면 **화면 전체가 그 색에 맞춰 다시 만들어져요.** 띠색,
  글씨색, 테두리 회색까지요. 색상환으로 직접 고를 수도 있어요
- 밝게 / 어둡게 / 시스템 따라가기. 바뀔 때 화면을 덮었다 걷어서 안 튀어요
- 자세한 규칙은 `DESIGN.md`에 숫자로 적혀 있어요

# 쓰고 고치기

## 올리기

`main`에 푸시하면 GitHub Actions가 알아서 해요. 손으로 올릴 일이 없어요.

| 바뀐 곳 | 올라가는 것 |
|---|---|
| 아무 데나 | 웹 화면 (`eoris1225.github.io/school-app`) |
| `supabase/functions/**` | 서버 함수 |
| `supabase/migrations/**` | **자동 아니에요.** `npx supabase db push` 를 손으로요 |

표를 늘렸으면 **`db push` 를 먼저** 하고 머지하세요. 순서가 뒤집혀도 안
죽게는 해뒀지만(없는 칸은 빼고 다시 물어봐요) 표 먼저가 깔끔해요.

다른 브랜치 화면을 보고 싶으면 **Actions 탭 › 웹 미리보기 배포 › Run
workflow** 에서 브랜치를 골라 실행하면 돼요.
다른 브랜치를 보여주고 싶으면 **Actions 탭 › 웹 미리보기 배포 › Run workflow**에서
브랜치를 골라 실행하면 돼요. (이 버튼은 워크플로가 `main`에 있어야 보여요)

## 폰에 앱처럼 깔기 (아이폰도 돼요)

위 주소를 폰 브라우저로 연 다음,

- **아이폰**: 사파리 아래 공유 버튼 › **홈 화면에 추가**
- **안드로이드**: 크롬 메뉴 › **홈 화면에 추가**

하면 홈 화면에 아이콘이 생기고, 누르면 주소창 없이 앱처럼 전체화면으로 떠요.

아이폰은 애플이 서명 안 된 앱 설치를 막아놔서, 안드로이드의 APK처럼 파일로 깔 수가
없어요. TestFlight를 쓰려면 애플 개발자 등록(연 $99)이 필요하고, 무료 계정으로 넣는
방법은 **7일마다 앱이 멈춰요**. 그래서 시험 삼아 써볼 때는 이 방법이 제일 나아요.

이게 되려면 내보낸 화면에 이름·아이콘·색이 적혀 있어야 해요. `public/` 폴더와
`scripts/add-pwa-tags.mjs`가 그 일을 해요. 로컬에서 똑같이 만들려면:

```bash
npm run build:web
```

## 웹으로 볼 때 알아둘 점

화면 구성, 색, 흐름은 실제 앱과 같아요. 다만 아이폰 전용 아이콘(SF Symbols)이
안드로이드용 아이콘으로 대체되고, 햅틱이나 네이티브 키보드 동작은 확인할 수 없어요.
그런 부분은 아래 Expo Go로 봐주세요.

## 아이콘을 바꾸고 싶으면

아이콘은 손으로 그린 게 아니라 `scripts/make-icon.py`가 그려요. 색 몇 줄만 고치고
`python3 scripts/make-icon.py`를 돌리면 앱용·안드로이드용·웹용 여덟 장이 한꺼번에
다시 나와요. (Pillow가 필요해요: `pip install pillow`)

## 글꼴

상황에 따라 두 벌을 나눠 써요.

- **Pretendard** — 한글과 일반 글씨. Regular / Medium / SemiBold / Bold 네 굵기예요.
- **Outfit** — 시각, 날짜, D-day처럼 숫자와 영문만 나오는 자리에 써요.
  숫자가 또렷해지고 화면이 단조롭지 않아요.

화면 코드에서는 `fontWeight`만 적으면 `src/components/text.tsx`가 알맞은 파일을
골라 주고, 숫자 자리에는 `<Text numeric>`을 쓰면 돼요.

용량을 줄이려고 Pretendard는 KS X 1001 완성형 한글 2,350자와 영문·기호만 남겨
줄여서 넣었어요 (2.6MB → 445KB/굵기). 여기에 없는 드문 글자는 폰 기본 글꼴로 나와요.

두 글꼴 모두 SIL Open Font License 1.1이에요. 자세한 안내는
`assets/fonts/LICENSE.md`에 있어요.

## 어떻게 만들어졌나

```
앱  ->  Edge Function (NEIS 키가 여기 있어요)  ->  NEIS
                  |
                  +-->  Supabase 표 (계정 · 쪽지 · 수행평가 · 교시 시각)
```

앱은 NEIS를 직접 안 불러요. 그러려면 인증키가 앱 안에 있어야 하는데,
앱에 넣은 값은 누구나 꺼내 볼 수 있거든요.

표도 앱이 직접 못 읽어요. RLS를 켜고 정책을 안 만들어 뒀어요. 함수만
`service_role` 키로 읽고, 그 키는 함수 안에만 있어요. 누가 무엇을 볼 수
있는지는 전부 함수가 정해요.

```
src/app/                화면 (expo-router 파일 기반)
  (tabs)/               홈 · 급식 · 시간표 · 달력 · 커뮤니티
  start.tsx             로그인 · 회원가입
  setup.tsx             가입 직후 안내 (전부 건너뛸 수 있어요)
  thread.tsx            쪽지 대화
  profile.tsx           내 정보 · 담당 과목 · 테마 · 알림
  add-event.tsx         수행평가 올리기 (선생님)
  bell-times.tsx        교시 시각 넣기 (선생님)
  pick-school.tsx       학교 찾기
  pick-class.tsx        학년 · 반 · 번호
  swap-subject.tsx      내가 듣는 과목으로 바꾸기

src/lib/
  api.ts                Edge Function 부르기
  app-state.tsx         앱 전체 상태. 계정과 기기 중 누가 이기는지도 여기서
  bells.ts              교시 시각 규칙
  live.ts               돌아올 때 / 보고 있을 때 다시 받아오기
  photo.ts              사진 고르고 줄이기
  push.ts               웹 푸시
  subject.ts            NEIS 과목 이름 -> 교과군 (색과 아이콘이 이걸로 정해져요)
  teacher-week.ts       학교 시간표에서 내 수업만 뽑기
  time.ts               지금 몇 교시인지
  korean.ts             조사 (로/으로, 을/를)

src/components/         공통 조각. text.tsx 가 굵기에 맞는 글꼴을 골라줘요
src/constants/          테마 색 (accent 하나로 밝은/어두운 팔레트를 만들어요)

supabase/functions/neis/   서버 함수 하나에 경로 열여덟 개
supabase/migrations/       표 (순서대로 쌓여요)
scripts/                   검사와 도구. scripts/README.md 참고
```

## 검사

세 가지가 있고 잡는 게 서로 달라요. `scripts/README.md`에 자세히 적어뒀어요.

```bash
# 계산 규칙 (deno)
deno run --allow-read --sloppy-imports scripts/check-bells.ts

# 서버 (deno) — GitHub Actions 도 이걸 돌려요
cd supabase/functions && deno test --allow-env --allow-read _shared/

# 브라우저 — 진짜로 그려진 화면을 봐요
npm run build:web && node scripts/browser-photo.mjs

# 진짜 서버
TEACHER_CODE=선생님코드 node scripts/live-check.mjs
```

**표에 칸을 늘렸으면 라이브 검사를 꼭 돌려보세요.** 흉내내는 검사는 표
권한이나 칸 이름이 어긋난 걸 못 잡아요. 그래서 네 번 데었어요.

지우면 안 되는 시험 계정 같은 건 없어요. 라이브 검사가 돌 때마다
`delete-me-`로 시작하는 계정을 새로 만들어요. 보이는 대로 지우세요.

## 키 관리

API 키는 코드에 절대 쓰지 말고 저장소 시크릿에 넣어요
(GitHub › Settings › Secrets, 또는 Codespaces 시크릿).

앱 코드에서 읽을 수 있는 값은 `EXPO_PUBLIC_` 접두사가 붙은 것뿐이에요.
접두사가 없는 값(`process.env.NEIS_API_KEY` 같은)은 앱 안에서는 `undefined`가 돼요.
